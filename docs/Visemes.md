# visemes marked

Prompt for viseme/expression sprite sheet generation:

```
Create a 2x2 sprite sheet of this character with the SAME face, SAME lighting, SAME art style, and SAME camera framing as the original image.

Generate four slight animation variations of the character performing the following face shape:
[INSERT VISEME OR EXPRESSION HERE]

Important requirements:
- add teeth in the mouth if necessary for the viseme/expression
- Keep the character’s identity unchanged.
- Keep the head angle and proportions identical to the original.
- Only modify the mouth, eyes, and local facial muscles required for the expression.
- No extra background details; match the original background exactly.
- Maintain consistent colors, shading, and texture.
- Each of the 4 frames should be a subtle progression of the same expression, suitable for a small looping animation.
```

---

# 🔤 **Core Viseme List (with descriptions)**

*(✔ = common / industry standard)*

* ✔ **“Rest viseme — relaxed neutral mouth, lips gently closed or slightly open”**

* ✔ **“A/I viseme — mouth open vertically, lips slightly stretched upward”**

(Covers A, I, E, Ä, AI sounds)

* ✔ **“E/EE viseme — wide horizontal smile shape, mouth stretched side to side”**

(Like saying ‘ee’ in ‘see’)

* ✔ **“O viseme — rounded lips forming a circular shape”**

* ✔ **“U viseme — small tight ‘puckered’ lips pushed forward”**

* ✔ **“F/V viseme — upper teeth touching the lower lip”**

* ✔ **“M/B/P viseme — lips fully closed, soft compression at the center”**

* ✔ **“L viseme — tongue touching upper teeth or slightly visible behind them”**

* **“TH viseme — tongue placed gently between upper and lower teeth”**

*(Optional — only for English / similar languages)*

* **“CH/J/SH viseme — rounded lips with slightly open mouth, soft inward tension”**

*(Optional — nice extra realism but not required)*

These are the ones almost everyone uses:

✔ E/EE
✔ O
✔ U
