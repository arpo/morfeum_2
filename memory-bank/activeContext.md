# Active Context

## Recent Changes (2025-12-10)

### Fixed `--furnish` Flag for GO_INSIDE (Dec 10)
- **Problem**: Running `/GO_INSIDE --furnish` had no visible difference from without the flag
- **Root cause**: `furnishingDetails` was being generated by LLM and used in image prompt, but NEVER saved to the node data
- **Fix**: 
  1. Added `FurnishingDetails` interface to `nodeBuilder.ts`
  2. Added `furnishingDetails` property to `NodeBuildOptions` and `LocationNode` interfaces
  3. Updated `buildNode()` to save furnishingDetails when present
  4. Updated `createNodePipeline.ts` to pass `furnishingDetails` to `buildNode()`
- **Files modified**:
  - `packages/backend/src/engine/generation/shared/nodeBuilder.ts` - Added FurnishingDetails interface and property
  - `packages/backend/src/engine/navigation/pipelines/createNodePipeline.ts` - Pass furnishingDetails to buildNode, added logging

### Improved Furnishing Prompt Emphasis (Dec 10)
- **Problem**: Even with furnishing details in prompt, FLUX rendered small furniture along walls
- **Fix**: Added strong emphasis statements to image prompt when `--furnish` is used:
  - "IMPORTANT: This space is FULLY FURNISHED and IN ACTIVE USE - NOT an empty room."
  - "Furniture and equipment FILL THE SPACE, distributed throughout the floor area"
  - "Items are HUMAN-SCALE and PROMINENTLY VISIBLE in foreground and midground"
  - Quantity guidance: "at least 4-8 pieces" and "occupy 40-60% of visible floor space"
- **File modified**: `packages/backend/src/engine/navigation/pipelines/createNodePipeline.ts`

## Data Flow: `--furnish` Flag

1. **navigation.ts**: `parseCommandFlags()` extracts `--furnish` from command text
2. **createNodePipeline.ts**: Passes `includeFurnishing` to `analyzeStructure()`
3. **structureAnalyzer.ts**: Passes to `structureAnalysisPrompt()`
4. **structureAnalysis.ts**: Adds `furnishingInstructions` to LLM prompt
5. **createNodePipeline.ts**: `composeImagePrompt()` adds strong furnishing emphasis
6. **nodeBuilder.ts**: Saves `furnishingDetails` to node data

## Difference: `suggestedFixtures` vs `furnishingDetails`

| Field | When Generated | Content |
|-------|---------------|---------|
| `suggestedFixtures` | Always (in structure) | Generic fixtures based on functionalType |
| `furnishingDetails` | Only with `--furnish` | Detailed items + placement notes |
